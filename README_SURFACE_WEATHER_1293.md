# Viewer v1.2.93 – Surface weather menu and scientific improvement

Full viewer distribution based on v1.2.92. In Data overlays, all regular overlay toggles remain grouped above a full-width Surface weather analysis section; it uses a two-column control layout where space permits. Surface weather still defaults OFF, with the same panel status and retry controls, and still appears in export output only when enabled.

The companion converter v1.4.84 is required for new surface-weather analyses. Existing v0.1 files may remain visible until regenerated; their algorithm version is in GeoJSON `metadata.algorithm`. This release does not alter how existing map, terrain, tracers, or observations are rendered.
