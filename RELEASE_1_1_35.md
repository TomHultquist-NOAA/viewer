# OMD EVU Model Viewer v1.1.35 — live map boundary contrast

Released 2026-11-02.

- Live maps use subtle two-tone geographic boundary strokes that remain legible over dark and bright weather shading. Coastlines, country/state lines, and zoom-eligible counties are supported.
- Casing and inner strokes share source geometry and visibility in 2D/Globe, both themes, expanded panels, and the Difference window. Existing county/detail thresholds are unchanged.
- Export-only outlines remain heavier than live map lines, as before.
- Grid display / Interpolate control height now matches the Map view select on desktop and stays compact elsewhere.

Install the viewer files at the existing web root; preserve operational data and local configuration. Browser caches may need to be refreshed when replacing an existing installation.
