# OMD EVU Model Viewer v1.1.37 — unified GIF frame cap

- Standard (1200 px) and High (1600 px) GIFs now each permit up to 25 frames, for both single-panel and all-panels exports.
- Both resolutions default to F000–F024 when those forecast hours are available. Existing range, step, delay, and final-frame hold controls remain unchanged.
- Keeps the cleaner two-tone boundary rendering introduced in v1.1.36 for PNG and GIF exports.
- No changes to forecast conversion, published model data, or viewer configurations.
